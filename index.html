Meus projetos

Assistente Virtual de Vacinação integrado com o Telegram

Desenvolvi junto com minha equipe, como projeto do 1° semestre da FATEC, um bot no Telegram que oferece acesso a vacinas por faixa etária, identifica as UBS mais próximas, permite agendar horários, enviar notificações por e-mail e integrar diretamente com o Google Agenda. O projeto foi desenvolvido em Python, com Ollama para processamento de áudio e linguagem natural, BeautifulSoup para Web Scraping, GeoPy para geolocalização e Pandas para manipulação dos dados. Para versionamento, foi utilizado Git/GitHub.

MusicStream - Player de música integrado com a API da Audius

O MusicStream é uma aplicação web de streaming de música inspirada no SoundCloud, desenvolvida com foco em uma experiência visual escura, moderna e minimalista. A aplicação foi construída em Python, com integração à API da Audius para fornecer um catálogo de músicas. Possui reprodução, avanço, retrocesso, controle de tempo, curtidas persistentes e autenticação básica de usuário. Stack principal: Flask, SQLite, HTML, CSS e JavaScript.
